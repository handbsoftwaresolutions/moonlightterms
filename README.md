# Moonlight

Legal documents for the Moonlight app, plus **Moonlight Local** — a fully private terminal LLM for Mac.

| Path | What |
|------|------|
| `moonlight-privacy-policy.html` | Privacy Policy |
| `moonlight-terms-of-service.html` | Terms of Service |
| [`moonlight-llm/`](./moonlight-llm/) | **Private Mac terminal LLM** |

## Quick start (Mac)

```bash
cd moonlight-llm
chmod +x install-mac.sh bin/moonlight
./install-mac.sh
moonlight
```

Everything runs on `127.0.0.1`. No API keys. No cloud. See [`moonlight-llm/README.md`](./moonlight-llm/README.md).
