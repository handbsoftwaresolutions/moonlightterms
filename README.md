# Moonlight

Legal documents for the Moonlight app, plus **Moonlight DevSec** — a GLM-5.2 terminal for cybersecurity and software development (not a chatbot).

| Path | What |
|------|------|
| `moonlight-privacy-policy.html` | Privacy Policy |
| `moonlight-terms-of-service.html` | Terms of Service |
| [`moonlight-llm/`](./moonlight-llm/) | **DevSec terminal (GLM-5.2)** |

## Quick start (Mac)

```bash
cd moonlight-llm
chmod +x install-mac.sh bin/moonlight
./install-mac.sh
moonlight
```

Default model: `glm-5.2:cloud` (GLM-5.2 via Ollama). See [`moonlight-llm/README.md`](./moonlight-llm/README.md).
